iOS and Android application connected to a CE Class IIa medical device that continuously monitors multiple physiological parameters. Features an advanced deep learning algorithm for predictive event detection, enabling early warning of cardiac decompensation and other critical health conditions. The system provides real-time analysis of vital signs, automated alerts, and personalized health insights to support proactive medical intervention.
