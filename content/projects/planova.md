A future-proof, opinionated Flutter app to manage your life in plain text: one Markdown daily file for events, todos and journal, plus free-form notes (Android and Linux). Version 1.3 brings a home-screen widget, event notifications, ICS import, a refill dialog to carry over undone todos, native file watching, and atomic saves so external edits (vim, Syncthing) are never lost. No account, no server: sync is yours to choose.
